# Commands Used - Day 8

## Become Root

```bash
sudo su -
```

---

## Verify Python

```bash
python3 --version
```

---

## Verify pip3

```bash
pip3 --version
```

---

## Locate pip3

```bash
which pip3
```

---

## Install Ansible 4.8.0

```bash
pip3 install ansible==4.8.0
```

---

## Verify Installation

```bash
ansible --version
```

---

## Locate Ansible Binary

```bash
which ansible
```

---

## Verify PATH

```bash
echo $PATH
```

---

## Check Installed Package

```bash
pip3 show ansible
```

---

## Useful Troubleshooting

Locate ansible manually

```bash
find / -name ansible 2>/dev/null
```

Check installed Python packages

```bash
pip3 list
```
